# userdb.txt — Cowrie accepted-login database
#
# Format (one entry per line):
#   username:uid:password
#
# Special password tokens:
#   *        accept ANY password for this username
#   !        reject this username/password combination
#   !*       reject ALL passwords for this username
#
# VERIFIED from Cowrie source (cowrie/core/checkers.py):
#   - Field separator is colon (:).
#   - uid field is present but largely ignored by the checker; use 0 for root, 1000 for others.
#   - Lines starting with # are comments.
#   - Blank lines are ignored.
#
# These credentials mirror the passwordRegex accepted by Beelzebub and DECEIVE
# so that the same scripted attacker sessions can be replayed against all three honeypots.
